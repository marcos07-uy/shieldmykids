# Product Vision

## Purpose

Shield My Kids helps parents and guardians manage screen time for child-owned or family-managed devices.

The product should focus on understandable family workflows instead of raw surveillance. Parents should be able to see how much time each child has used, which devices contributed to that time, and whether current rules are being enforced.

## Product Principles

1. Transparent to children.
2. Controlled by verified parents or guardians.
3. Minimal and purposeful data collection.
4. Honest about platform enforcement limits.
5. Useful before it is comprehensive.
6. Designed for low operating cost.

## Target Users

Primary user:

- Parent or guardian managing a small family set of devices.

Secondary user:

- Child using a managed Windows or Android device.

Initial deployment user:

- One technical owner running the system for one family.

## Product Outcomes

The product should answer these questions:

- How much screen time did each child use today?
- Which devices contributed to that usage?
- Which apps or app categories consumed time, where available?
- Is the child currently allowed, warned, locked, or blocked?
- What rules are active?
- What changed recently?
- Did device enforcement succeed?

## MVP Product Shape

The MVP is not a full commercial parental-control platform.

The MVP should include:

- Parent login.
- Child profiles.
- Device enrollment.
- Device heartbeats.
- Usage reporting.
- Daily screen-time limits.
- Basic schedule rules.
- Manual lock/unlock.
- Usage summary.
- Audit log.
- Windows enforcement.
- Android monitoring.

The MVP should defer:

- iOS.
- macOS.
- Payment.
- Public app-store release.
- Location tracking.
- Browser history collection.
- Screenshot capture.
- Keystroke logging.
- AI recommendations.
- Enterprise tenancy.

## Transparency Requirements

Every child-facing agent must clearly indicate:

- The device is managed.
- Screen-time rules may be enforced.
- Usage is being reported to the parent account.
- The product name or family-visible identity.

There must be no hidden surveillance mode.
