# Gemini Context

Shield My Kids is a documentation-first project with an initial minimal backend slice now present.

Before making changes, read:

- [AGENTS.md](AGENTS.md)
- [CODEX.md](CODEX.md)
- [codex.md](codex.md)
- [docs/agent-context/codex-context.md](docs/agent-context/codex-context.md)

The Phase 0 documentation baseline is complete. Existing implementation is limited to the minimal backend Lambda and Terraform dev environment already present in the repository.

Do not expand implementation beyond that slice without explicit user approval. Do not deploy infrastructure or mutate AWS resources without explicit user approval.

Without explicit approval, do not add:

- Parent dashboard implementation.
- Windows or Android agent implementation.
- Production infrastructure.
- Package manifests.
- CI workflows.
- Build scripts.

The product must remain a transparent parental-control system. Do not design covert monitoring or spyware capabilities.
